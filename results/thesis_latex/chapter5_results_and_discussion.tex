\chapter{RESULTS AND INFERENCES}
\label{chap:results_and_discussion}
\label{chap:results}

This chapter presents the empirical evaluation, algorithmic verification, and experimental findings of the proposed two-stage continual intrusion detection framework on the TON\_IoT network telemetry benchmark~\cite{alshammari2020toniot}. Following rigorous IEEE academic standards, the investigation is structured as a cohesive, unified scientific narrative pairing comprehensive quantitative measurements with deep analytical inferences.

The remainder of this chapter is organized as follows. Section~\ref{sec:impl_workflow} establishes the experimental setup, data hygiene protocol, and leave-one-attack-out evaluation matrix. Section~\ref{sec:phase1_4_results} evaluates the closed-world Random Forest baseline on familiar IoT network traffic and empirically demonstrates the catastrophic failure of static models when confronted with unobserved zero-day attacks, substantiated by a complete $10 \times 10$ confusion matrix. Section~\ref{sec:phase5_results} assesses the operational screening efficacy of the unsupervised Isolation Forest novelty screener across benign normal, familiar attack, and novel zero-day traffic streams. Section~\ref{sec:phase6_7_results} benchmarks four continual learning paradigms on rare zero-day intrusions, examining the core trade-offs governing plasticity, stability, memory overhead, and retraining latency. Section~\ref{sec:phase7_1_results} characterizes the memory--retention Pareto frontier through systematic buffer sensitivity sweeps across decreasing memory budgets. Section~\ref{sec:phase8_9_10_results} validates the volume-aware Dynamic Replay rule across four diverse cyber attack families spanning an $18\times$ volumetric range, providing detailed per-class retention breakdowns for ransomware, cross-site scripting, and backdoor intrusions alongside a 20-configuration consolidated benchmark. Finally, Section~\ref{sec:resource_synthesis} evaluates the physical memory footprint, execution latency, and edge deployment viability, verifying compliance against all seven system design requirements.

\subsection{Data Hygiene, Leakage Prevention, and De-Identification}
\label{subsec:data_hygiene}

The raw TON\_IoT network telemetry dataset (\texttt{train\_test\_network.csv}) comprises $211{,}043$ flow records across $44$ network attributes. In raw form, missing connection fields are represented by dash characters (\texttt{'-'}), and each record includes a binary indicator (\texttt{label}) and a ten-class category string (\texttt{type}), alongside source and destination IP addresses (\texttt{src\_ip}, \texttt{dst\_ip}).

To prevent experimental artefacts and guarantee that models learn generalisable flow dynamics rather than testbed identities, four mandatory hygiene steps are executed:
\begin{enumerate}
    \item \textbf{Missing Value Standardization:} All \texttt{'-'} string placeholders are mapped to formal missing value markers (\texttt{NaN}).
    \item \textbf{Target Leakage Prevention:} The binary \texttt{label} attribute is permanently removed from the feature matrix so that ground-truth classification labels cannot leak into input vectors.
    \item \textbf{Network Identifier Stripping:} Both \texttt{src\_ip} and \texttt{dst\_ip} are stripped. In static testbeds, attacking hosts are assigned dedicated private IP addresses; if IP strings are retained, decision trees split directly on specific host addresses, memorising static node identities rather than behavioural network characteristics.
    \item \textbf{Exact Row Deduplication:} After removing IP addresses, exact duplicate rows across the remaining attributes are eliminated. Prior to IP removal, the dataset contained $20{,}569$ duplicates; removing host addresses exposed an additional $6{,}882$ identical flows, yielding $27{,}451$ total dropped duplicates and a clean, deduplicated corpus of $183{,}592$ unique records.
\end{enumerate}

All statistical transformations are fitted strictly on the historical training partition $\mathcal{D}_{\text{train}}$:
\begin{itemize}
    \item \textbf{Sparse Attribute Pruning:} Any column containing $50\%$ or more missing entries within $\mathcal{D}_{\text{train}}$ is discarded across all partitions.
    \item \textbf{Train-Only Imputation:} Missing numerical values are imputed using the column-wise median computed strictly over $\mathcal{D}_{\text{train}}$. Missing categorical fields are imputed using the training mode.
    \item \textbf{Categorical Encoding:} Categorical attributes (transport protocol \texttt{proto} and connection state \texttt{conn\_state}) are encoded using a one-hot encoder fitted exclusively on $\mathcal{D}_{\text{train}}$, with unobserved runtime categories mapped to all-zero vectors.
    \item \textbf{Hash-Based Leakage Verification:} 64-bit row hashes computed over the encoded feature matrices confirm that fewer than $0.05\%$ of evaluation rows share identical feature vectors with training records, confirming negligible train--test overlap.
\end{itemize}

\subsection{Leave-One-Attack-Out Partitioning Protocol}
\label{subsec:leave_one_out}

To evaluate zero-day adaptation rigorously, the study adopts a Leave-One-Attack-Out experimental protocol across four diverse attack families: Man-in-the-Middle (MITM), Ransomware, Cross-Site Scripting (XSS), and Backdoor. For each experiment:
\begin{enumerate}
    \item All records belonging to the withheld attack class $c_{\text{unseen}}$ are isolated into an unobserved partition $\mathcal{D}_{\text{unseen}}$.
    \item The remaining records belonging to the $K = 9$ known classes ($\mathcal{D}_{\text{known}}$) are partitioned via a stratified 70/30 split into the historical training archive $\mathcal{D}_{\text{train}}$ and the known evaluation set $\mathcal{D}_{\text{test\_known}}$.
    \item The withheld attack partition $\mathcal{D}_{\text{unseen}}$ is divided chronologically into an adaptation batch $\mathcal{D}_{\text{new}}$ ($20\%$, comprising $M$ flows) and an untouched evaluation batch $\mathcal{D}_{\text{eval\_new}}$ ($80\%$).
\end{enumerate}

\subsection{Benchmarked Adaptation Strategies and Continual Metrics}
\label{subsec:strategies_and_metrics}

When the confirmed novel attack batch $\mathcal{D}_{\text{new}}$ arrives at Stage~2, four continual learning paradigms are benchmarked:
\begin{enumerate}
    \item \textbf{No Update Baseline:} The initial Random Forest model is evaluated without modification ($F1_{\text{new}} = 0.0000$).
    \item \textbf{Strategy A (Full Historical Retraining):} The model is completely retrained on all historical data merged with the new attack batch ($\mathcal{B} = \mathcal{D}_{\text{train}}$, $|\mathcal{B}| = 115{,}417\text{--}127{,}787$).
    \item \textbf{Strategy B (Class-Balanced Static Replay):} A fixed quota $k \in \{25, 50, 100, 200, 500\}$ is sampled uniformly from each known class ($|\mathcal{B}| = 9\,k$).
    \item \textbf{Proposed Dynamic Volume Replay:} The per-class quota $k_{\text{dyn}}$ is dynamically computed based on incoming batch size $M$:
    \begin{equation}
    k_{\text{dyn}} = \min\!\left( k_{\max},\; \max\!\left( k_{\min},\; \left\lfloor \frac{M \cdot \alpha}{K} \right\rfloor \right) \right), \qquad \alpha = 1.0, \; k_{\min} = 100, \; k_{\max} = 555.
    \end{equation}
\end{enumerate}

Adaptation performance is quantified across seven standardized metrics:
\begin{itemize}
    \item \textbf{Novel Attack Plasticity ($F1_{\text{new}}$):} F1 score evaluated on the untouched evaluation set $\mathcal{D}_{\text{eval\_new}}$.
    \item \textbf{Average Forgetting ($\mathcal{F}_{\text{avg}}$) and Maximum Forgetting ($\mathcal{F}_{\max}$):} The mean and worst-case drop in per-class F1 across the $K=9$ known classes relative to pre-adaptation baseline performance.
    \item \textbf{Backward Transfer (BWT):} Defined as $\text{BWT} = -\mathcal{F}_{\text{avg}}$, measuring retention or enhancement of historical knowledge.
    \item \textbf{Memory Reduction Ratio (MRR):} Percentage reduction in retained exemplar storage relative to full retraining: $\text{MRR} = 100 \times (1 - |\mathcal{B}| / |\mathcal{D}_{\text{train}}|)$.
    \item \textbf{Plasticity--Stability Index (PSI):} The harmonic mean of novel-attack F1 and retained historical stability:
    \begin{equation}
    \text{PSI} = \frac{2 \cdot F1_{\text{new}} \cdot (1 - \max(0, \mathcal{F}_{\text{avg}}))}{F1_{\text{new}} + (1 - \max(0, \mathcal{F}_{\text{avg}}))}.
    \end{equation}
    \item \textbf{Edge IoT Viability Index (EIVI):} A composite metric (0--100) weighting plasticity ($35\%$), stability ($35\%$), memory reduction ($25\%$), and update speed ($5\%$).
\end{itemize}

\textbf{Technical Inferences on Baseline Behavior and Closed-World Failure:}
\begin{enumerate}
    \item \textbf{Structural Impossibility of Closed-World Zero-Day Recognition:} On the 54{,}766 known-class test flows, the Random Forest achieves $99.02\%$ accuracy and $0.9890$ Macro-F1 (Table~\ref{tab:full_confusion_matrix}). Even on the combined 55{,}805-flow stream, headline accuracy remains seemingly high at $97.17\%$. Yet, because the tree ensemble's leaves map strictly to the $K = 9$ known training classes, every single flow of the withheld MITM class is misclassified ($F1_{\text{MITM}} = 0.0000$).
    \item \textbf{Dual Operational Hazard (Silent Evasion vs.\ Collateral Precision Loss):} The misrouted flows create two distinct operational failures at the edge gateway. The $29.26\%$ of MITM flows routed to \texttt{normal} evade detection completely, entering the protected IoT subnet silently. Simultaneously, the $39.85\%$ routed to \texttt{dos} contaminate DoS alerts, dragging DoS precision down from $0.989$ to $0.903$ and reducing DoS F1 from $0.9855$ to $0.9411$.
\end{enumerate}

\textbf{Technical Inferences on Continual Update Paradigms:}
\begin{enumerate}
    \item \textbf{Failure of Full Retraining on Rare Threats:} Merging $207$ MITM flows with $127{,}787$ historical flows gives MITM an extreme minority share of just $0.16\%$. In CART tree induction, Gini impurity reduction $\Delta I(s) = I(s) - \frac{|s_L|}{|s|}I(s_L) - \frac{|s_R|}{|s|}I(s_R)$ weights split quality by sample volume. Candidate splits isolating rare MITM records provide negligible impurity gains at upper tree levels, causing trees to subsume MITM into larger classes. As a result, $52.04\%$ of MITM evaluation flows are misclassified, yielding a mediocre F1 of $0.6483$.

\end{enumerate}

\textbf{Technical Inferences on Buffer Sizing and Sensitivity:}
\begin{enumerate}
    \item \textbf{High Plasticity at Minimal Memory ($k = 25$):} Retaining just $25$ exemplars per class ($225$ flows total, $99.82\%$ storage reduction) achieves $0.9804$ MITM F1. This confirms that tree ensembles need very few historical anchors to delineate an unobserved threat class.
    \item \textbf{Identification of the $k_{\min} = 100$ Pareto Knee:} Increasing $k$ from $25$ to $100$ slashes average forgetting $\mathcal{F}_{\text{avg}}$ by $58.7\%$ ($0.0634 \rightarrow 0.0262$) and maximum forgetting $\mathcal{F}_{\max}$ by $52.3\%$ ($0.1266 \rightarrow 0.0604$), requiring only $675$ additional exemplars ($129.6\text{ KB}$) and $9.5\text{ ms}$ of computation. Above $k=200$, minority dilution begins to set in, reducing MITM recall from $0.9615$ to $0.9255$ at $k=500$.
\end{enumerate}

\section{Cross-Attack Generalization and Multi-Volume Case Studies}

\textbf{Key Analytical Insights from Tables~\ref{tab:case_study_ransomware}--\ref{tab:case_study_backdoor}:}
\begin{enumerate}

In summary, the empirical results confirm that static intrusion detectors experience catastrophic failure on unobserved threats, that lightweight unsupervised screening provides an effective trigger for continuous adaptation, that class-balanced replay resolves minority dilution on rare attacks, and that volume-aware Dynamic Replay suppresses severe forgetting spikes under volumetric surges while preserving $>96.7\%$ memory savings and sub-$0.1\text{ s}$ retraining latency. Chapter~\ref{chap:conclusion} synthesizes the broader conclusions of this research and outlines directions for future inquiry.
